Category · eBay API

          
Key app Production ở developer.ebay.com — chỉ đọc danh mục, không đụng acc bán hàng.
            Thứ tự chọn Category: gõ tay ở bảng → quy tắc ép bên dưới → eBay gợi ý.

          
Chưa có eBay API — tool sẽ không tự chọn Category và không tự điền item specifics (phải gõ Category ID từng dòng).

          

            
            
          

          

            
            
          

          
Quy tắc ép Category (tuỳ chọn)

          
Khi muốn 1 nhóm hàng luôn vào Category cố định. Tìm từ khoá trong tên + danh mục sản phẩm; quy tắc của đúng site được xét trước, rồi tới quy tắc "(mọi site)", trên cùng khớp trước. Item specifics dạng Type=Dress|Style=A-Line.

Prompt — quy tắc AI dùng để viết tiêu đề

          
Sửa trực tiếp được (nên viết tiếng Anh). Tool luôn tự thêm phía sau: danh sách tên hãng + từ cấm, yêu cầu trả về JSON và dữ liệu sản phẩm —
            nên không cần ghi những phần đó. Sau khi AI trả về, tool vẫn tự lọc tên hãng / ký tự lạ và cắt về 80 ký tự.

Proxy

          
Dán proxy vào ô dưới (mỗi dòng ip:port:user:pass hoặc ip:port). Sau khi lưu, tool chỉ hiện
            IP:port — user/pass được cất kín, không hiện lại trên giao diện. Tool tự đổi proxy khi bị chặn / rớt mạng.

Proxy riêng theo site

          
Site có proxy riêng chạy theo thứ tự: IP gốc → proxy riêng → proxy chung. Site không có ở đây chỉ dùng proxy chung.
            Ví dụ Best Buy: IP Việt Nam dân cư + vài proxy Mỹ ở dải mạng khác nhau.
